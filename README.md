# Movie Trailer Website 🎬

A 3-page website built with HTML5, CSS, and JavaScript.

## Live Demo
🌐 https://hiralama123.github.io/movie_trailer

## Features
- Home page with 5 movie trailers
- Registration form with validated input fields
- Movie showings table
- HTML5 Canvas API custom styled banner
- Consistent CSS styling and navigation across all pages

## Tech Stack
- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API

## Pages
1. **Home** → Movie trailers showcase
2. **Register** → Validated registration form
3. **About** → Movie showings table
